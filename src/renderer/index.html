Installing Luma UE for STAR WARS Jedi: Fallen Order

Deploying the files is only half of this -- the DLSS call OptiScaler needs won't exist until you also turn DLSS on inside Luma's own overlay, in-game. Follow all of these steps in order.

  1. Check the licence checkbox below, in the Luma UE section of this Edit Game screen. Luma Framework's licence needs your explicit confirmation before this app will fetch anything on your behalf -- it always downloads live from the official GitHub release, never a bundled copy.
  2. Click "Deploy Luma UE". This downloads and places everything Luma needs directly in the game's folder: its shader files, its own dxgi.dll renamed to ReShade64.dll, its compiled add-on, and nvngx_dlss.dll. OptiScaler itself must already be installed for this game first (use the Install button) -- Deploy only adds Luma on top of that.
  3. On AMD or Intel graphics, also check the workaround checkbox beneath Deploy (applies Spoofing.Dxgi=false and Dx11withDx12.DontUseNTShared=true to OptiScaler.ini, per the OptiScaler wiki's own setup page for this game). Skip it on NVIDIA.
  4. Launch the game normally (through this app or Steam) and get into actual gameplay, not just a menu or loading screen.
  5. Press the Home key in-game. This opens Luma's own overlay -- it is separate from OptiScaler's menu (Alt+Home) and won't appear unless deploy actually succeeded.
  6. Select DLSS as the upscaling method inside Luma's overlay. This is the step that actually matters: until DLSS is chosen here, the game keeps using its own stock TAA, no DLSS call ever happens, and OptiScaler's Neural Rendering panel will keep saying "waiting for the upscaler to run" indefinitely -- correctly, because nothing is running for it to hook yet.
  7. Open OptiScaler's own menu (Alt+Home) and check the DLSS 5 Neural Rendering panel to confirm it's picked up a real evaluate call.

Known open upstream issue (Luma-Framework #122, unresolved): opening any in-game menu after this can cause brief character pop-in and visible noise. That's a Luma bug, not something wrong with your setup.
